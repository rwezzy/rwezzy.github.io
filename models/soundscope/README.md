# SoundScope adjustable carrier

`carrier-v3.glb` is a display export of Keith Rwezahura's adjustable SoundScope carrier v3. It is assembled from the original CAD, rather than arranged flat as on a print bed. It contains 18 named printed parts: the shared frame, camera pressure bar, two camera screws and nuts, and three sets of microphone shoes, locking screws, toes and toe screws.

Units are metres, Y is up, and +Z faces the scene. The display mesh uses a 0.12 mm tessellation tolerance and 16-bit indices (604 KB). Use the original project CAD for fabrication; this file is for the portfolio viewer.

The website adds simple dimensional placeholders for the camera and microphone board. Those shapes and lens/microphone symbols are explanatory geometry, not manufacturer CAD or an exact electrical layout. The tripod, USB cables and board components are omitted. The camera envelope is approximately 89.5 × 25 × 30 mm; the nominal board is 100 × 1.2 mm. The carrier's adjustments accommodate the fit. An exploded view illustrates the parts; it is not an assembly instruction.

No manufacturer meshes, third-party artwork, generated images or textures are included. The original carrier design and this export belong to Keith Rwezahura. The viewer uses Three.js (MIT), already used elsewhere on this site.
